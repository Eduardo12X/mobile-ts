Import this only if it recommends:
Import-Module PSReadLine
Check the current version of node:
node -v
Create a package.json in terminal:
npm init -y
The package.json should like:
{
  "name": "aula1",
  "version": "1.0.0",
  "main": "index.js",
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1",
    "start": "ts-node"
  },
  "keywords": [],
  "author": "",
  "license": "ISC",
  "description": ""
}
Shows all the files and subfolders from the selected folder:
dir
Install the Typescript language:
npm install typescript ts-node
Create a tsconfig.json file:
npx tsc --init
Run the typescript file (the path changes depending on your files and folders):
npm start .\src\1 - sequential\helloWorld.js
