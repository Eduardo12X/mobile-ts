Order the git to observer the specfic path:
git init
Add every file and folder into the specified path:
git add .
Before the commit, you should specify your email and username:
git config --global user.email "you@example.com"
git config --global user.name "Your Name"
Create a implementation:
git commit -m "chore: Criar arquivos e diretórios de configuração" (example)
Creates a isolated enviroment/workspace
git branch -M main
Add the path where the folders and files will be in github:
git remote add origin https://github.com/Eduardo12X/mobile-ts.git
Put all the selected folders and files to the repository:
git push -u origin main
